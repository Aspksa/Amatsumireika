# Amatsumireika

Локальный когнитивный атлас. Вдохновлён визуализацией TRACKTOR из пользовательского видео (26 секунд); оригинальная реализация, без копирования исходного кода.

## Запуск
Windows: Python 3.10+ и Node.js 20+ с npm, затем Start.bat. При первом запуске npm устанавливает только TypeScript для сборки. После сборки Python работает без сети. Для ручного запуска: npm install --no-audit --no-fund, npm run build, python server.py.
Linux: те же команды (python3 server.py).

## Визуализация
Командный центр: живое ядро, орбиты, независимые панели. Атлас: радиальная карта, круглые кластеры, шестиугольные соты. Колесо — масштаб под курсором, перетаскивание — перемещение, двойной щелчок — фокус, кнопка «Сброс» — камера. Наведение — данные и связанные записи, выбор — фиксация. Палитры и скорость/плотность настраиваются.
При пустой БД видна явно обозначенная демонстрация; она не является памятью. Добавление записи переключает на настоящие данные SQLite. Для связи выберите две реальные записи в панели. На общем масштабе отображается ограниченная выборка узлов каждой категории, число записей показывается полностью.
Облачные вызовы, чат, аватар и автоматическое самообучение пока не реализованы. Не требуется Docker, Ollama или внешний сервер.

## v0.3 — Навигация и шесть представлений
На главной нажмите на центр ядра или кнопку «Атлас памяти». Возврат — кнопка в шапке или Escape. В атласе доступны кольца, круги, соты, силовой граф (ограниченные итерации притяжения/отталкивания), плитки и HUD. Силовой, плиточный и HUD режимы — собственные интерпретации, не точные копии видео. Категории/логические папки, сворачивание групп, сила связей, размер групп, подписи при увеличении, презентация с выходом по Escape. Поля папок хранятся в SQLite с миграцией старых записей; это логические метки, не файловый менеджер. При более 9 папках последние агрегируются, поиск видит все. Настройки визуализации сохраняются в браузере.

## v0.4 Deep Visualization
Четыре слоя частиц, импульсы, интерактивные орбиты, квадратные записи, межгрупповые связи, адаптивные кластеры, увеличение детализации, клавиша /, панель поверх полного атласа, календарь и журнал реальных операций. Матрица показывает распределение записей по категориям и остаткам ID, а не выполнение когнитивных задач. Настройки сохраняются через /api/settings в SQLite, журнал через /api/events (последние 500 событий). Существующие записи не получают вымышленные даты. При большом числе записей показана ограниченная выборка до 600 на группу; полная база доступна через поиск. Размеры, переходы и значки — оригинальная адаптация видеореференса.

## v0.5 Precision Visual Engine
Геометрия по видеореференсу: крупное ядро и внешние модули, ветвящиеся записи, плотные соты с общей геометрией, кольцевые кластеры с мини-значками, компактная панель и палитры. Камера учитывает свободную область экрана, область клика совпадает с радиальным значком, выборка рассчитывается для конечного зума до фокусировки. Девять категорий проекта не подменяются бизнес-данными оригинала. Без новых зависимостей.

## v0.6 Living Atlas
Все логические папки доступны без объединения в девять групп. Пагинация списка, вложенная навигация, динамические кольца и соты, лимит визуальных точек 1500–6000 по скорости кадра, пространственный индекс и отсечение невидимых записей. Даты новых записей сохраняются в SQLite; старые даты остаются неизвестными. Статистика показывает реальные события журнала за 7 дней (последние 500), а не работу LLM. Тесты SQLite на 1k/10k/50k/100k записей не являются тестом FPS. Физические документы, центральный файл личности и реальные рутины требуют отдельных модулей и здесь не имитируются. Координаты стабильны в рамках сеанса по слотам; радиальные сектора меняются при росте. Без новых зависимостей.

## v0.7 — Командный центр
На главной слева часы, дата, часовой пояс, календарь и события; по центру живое ядро; справа чат на всю высоту. Структура, поиск и управление доступны в отдельном атласе. Чат сохраняет сообщения в SQLite, показывает последние 200, поддерживает Enter/Shift+Enter и команды /помощь, /статус. Модель не подключена, ответы системы явно помечены; внешние API не вызываются. На узких экранах блоки располагаются вертикально.

## v0.8 — Chronograph
Левую панель заменяет единый радиальный календарь: часы в центре, месяцы снаружи, цвет и высота луча обозначают тип дня и его порядковый номер. Прошедшие дни яркие, будущие приглушённые; новый день включается по локальной дате устройства. Год автоматически меняется при наступлении 1 января, ручное переключение 2026/2027 доступно. При неизвестном годе нормы не выдумываются. Производственные данные РФ для пятидневки: ст. 112 ТК РФ, постановления № 1466 от 24.09.2025 и № 1187 от 17.09.2026. Источники: https://www.consultant.ru/law/ref/calendar/proizvodstvennye/2026/ и https://www.consultant.ru/law/ref/calendar/proizvodstvennye/2027/ . Региональные праздники и индивидуальные графики не учитываются. Работает без интернета, без новых зависимостей. Тесты проверяют нормы, переносы и смену года.

## v0.9 — Eternal Time
Спиральные лучи, двухслойное цветовое смешивание, золотой указатель, мягкая глубина и волна/рост нового дня; анимации отключены при reduced motion. Месяц открывается нажатием на его подпись/нижнюю статистику, двойной щелчок или кнопка назад возвращает год. Остаток рабочих дней включает текущий день; часы прошедших дней — плановая норма, не фактический табель. При пробуждении/возврате вкладки дата перечитывается; проверка расхождения системных и монотонных часов выявляет скачки, но не подтверждает абсолютную точность времени.
Обновления: фиксированный HTTPS-манифест calendar/production-calendar.json в main, проверка схемы, дат, разрешённых доменов, ссылки на постановление, отметки проверки сопровождающим и итоговых норм; локальный SQLite-кеш. Не перезаписывает существующие годы; при отсутствии данных текущего года или с сентября при отсутствии данных следующего года пробует обновление один раз в день на открытой странице, ручная проверка доступна. Источники постановлений проверяет сопровождающий при подготовке манифеста, программа не утверждает юридическую достоверность автоматически. Если репозиторий закрыт или сеть недоступна, остаются локальные данные. При запуске сервер также загружает проверенный локальный манифест из комплекта проекта. Новые годы публикуются только после проверки утверждённого календаря. Без новых зависимостей.

## v1.0 — Singularity of Time
Single radial spiral chronograph: one ray per day, an open outer edge, cached geometry, month drilldown, live clock with full date and weekday, and a gold light trail along elapsed days. Reduced motion respected. Old snapshots open in the spiral. Timeline: date selection, year/event playback, date-linked real records, chat event counts without text, SQLite snapshots of counters and mode, chronological category summary. Production ledger: employees, 5/2 federal plan, personal 6/1 pattern (not a certified six-day calendar), 2/2 anchor, manual shifts, absences, plan/fact, monthly workload indicators, remaining planned hours and XLSX export (up to 200 employees). Delta is only factual minus planned hours, not legal overtime. Unknown actual hours stay unknown; plans are not attendance. Timeline samples bounded at 500 rows; snapshots are metadata, not historical DB backups. No LLM or real personality/learning metrics are invented. No dependencies. Experimental shapes are 2D projections, not literal 4D or physical time simulation. Browser visual verification remains separate from CI.

## v1.2 — Clean Live Chronograph
Home opens the current calendar year automatically with the next-year switch at local midnight. The year buttons and five secondary sections are removed from the home panel; existing event/calendar/history/effects/work tools remain accessible under Atlas → Дополнительные инструменты времени, and SQLite records are unchanged.
