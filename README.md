# Amatsumireika

Локальный когнитивный атлас. Вдохновлён визуализацией TRACKTOR из пользовательского видео (26 секунд); оригинальная реализация, без копирования исходного кода.

## Запуск
Windows: Python 3.10+ и Node.js 20+ с npm, затем Start.bat. При первом запуске npm устанавливает только TypeScript для сборки. После сборки Python работает без сети. Для ручного запуска: npm install --no-audit --no-fund, npm run build, python server.py.
Linux: те же команды (python3 server.py).

## Визуализация
Командный центр: живое ядро, орбиты, независимые панели. Атлас: радиальная карта, круглые кластеры, шестиугольные соты. Колесо — масштаб под курсором, перетаскивание — перемещение, двойной щелчок — фокус, кнопка «Сброс» — камера. Наведение — данные и связанные записи, выбор — фиксация. Палитры и скорость/плотность настраиваются.
При пустой БД видна явно обозначенная демонстрация; она не является памятью. Добавление записи переключает на настоящие данные SQLite. Для связи выберите две реальные записи в панели. На общем масштабе отображается ограниченная выборка узлов каждой категории, число записей показывается полностью.
Облачные вызовы, чат, аватар и автоматическое самообучение пока не реализованы. Не требуется Docker, Ollama или внешний сервер.

## v0.8 — Chronograph
Левую панель заменяет единый радиальный календарь: часы в центре, месяцы снаружи, цвет и высота луча обозначают тип дня и его порядковый номер. Прошедшие дни яркие, будущие приглушённые; новый день включается по локальной дате устройства. Год автоматически меняется при наступлении 1 января, ручное переключение 2026/2027 доступно. При неизвестном годе нормы не выдумываются. Производственные данные РФ для пятидневки: ст. 112 ТК РФ, постановления № 1466 от 24.09.2025 и № 1187 от 17.09.2026. Источники: https://www.consultant.ru/law/ref/calendar/proizvodstvennye/2026/ и https://www.consultant.ru/law/ref/calendar/proizvodstvennye/2027/ . Региональные праздники и индивидуальные графики не учитываются. Работает без интернета, без новых зависимостей. Тесты проверяют нормы, переносы и смену года.

## v0.9 — Eternal Time
Спиральные лучи, двухслойное цветовое смешивание, золотой указатель, мягкая глубина и волна/рост нового дня; анимации отключены при reduced motion. Месяц открывается нажатием на его подпись/нижнюю статистику, двойной щелчок или кнопка назад возвращает год. Остаток рабочих дней включает текущий день; часы прошедших дней — плановая норма, не фактический табель. При пробуждении/возврате вкладки дата перечитывается; проверка расхождения системных и монотонных часов выявляет скачки, но не подтверждает абсолютную точность времени.
Обновления: фиксированный HTTPS-манифест calendar/production-calendar.json в main, проверка схемы, дат, разрешённых доменов, ссылки на постановление, отметки проверки сопровождающим и итоговых норм; локальный SQLite-кеш. Не перезаписывает существующие годы; при отсутствии данных текущего года или с сентября при отсутствии данных следующего года пробует обновление один раз в день на открытой странице, ручная проверка доступна. Источники постановлений проверяет сопровождающий при подготовке манифеста, программа не утверждает юридическую достоверность автоматически. Если репозиторий закрыт или сеть недоступна, остаются локальные данные. При запуске сервер также загружает проверенный локальный манифест из комплекта проекта. Новые годы публикуются только после проверки утверждённого календаря. Без новых зависимостей.
