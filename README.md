# Amatsumireika

Локальный когнитивный атлас. Вдохновлён визуализацией TRACKTOR из пользовательского видео (26 секунд); оригинальная реализация, без копирования исходного кода.

## Запуск
Windows: Python 3.10+ и Node.js 20+ с npm, затем Start.bat. При первом запуске npm устанавливает только TypeScript для сборки. После сборки Python работает без сети. Для ручного запуска: npm install --no-audit --no-fund, npm run build, python server.py.
Linux: те же команды (python3 server.py).

## Визуализация
Командный центр: живое ядро, орбиты, независимые панели. Атлас: радиальная карта, круглые кластеры, шестиугольные соты. Колесо — масштаб под курсором, перетаскивание — перемещение, двойной щелчок — фокус, кнопка «Сброс» — камера. Наведение — данные и связанные записи, выбор — фиксация. Палитры и скорость/плотность настраиваются.
При пустой БД видна явно обозначенная демонстрация; она не является памятью. Добавление записи переключает на настоящие данные SQLite. Для связи выберите две реальные записи в панели. На общем масштабе отображается ограниченная выборка узлов каждой категории, число записей показывается полностью.
Облачные вызовы, чат, аватар и автоматическое самообучение пока не реализованы. Не требуется Docker, Ollama или внешний сервер.

## v0.3 — Навигация и шесть представлений
На главной нажмите на центр ядра или кнопку «Атлас памяти». Возврат — кнопка в шапке или Escape. В атласе доступны кольца, круги, соты, силовой граф (ограниченные итерации притяжения/отталкивания), плитки и HUD. Силовой, плиточный и HUD режимы — собственные интерпретации, не точные копии видео. Категории/логические папки, сворачивание групп, сила связей, размер групп, подписи при увеличении, презентация с выходом по Escape. Поля папок хранятся в SQLite с миграцией старых записей; это логические метки, не файловый менеджер. При более 9 папках последние агрегируются, поиск видит все. Настройки визуализации сохраняются в браузере.
